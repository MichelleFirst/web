Álgebra Booleana y Circuitos Combinatorios

Explora, aprende y resuelve ejercicios sobre álgebra booleana y su aplicación en circuitos digitales.

¿Qué es el Álgebra Booleana?

El álgebra booleana es una rama de las matemáticas que se encarga del estudio de variables que solo tienen dos valores posibles: 1 (verdadero) y 0 (falso). Es ampliamente utilizada en la informática, electrónica digital y diseño de circuitos lógicos.

Se utiliza para simplificar el diseño de circuitos mediante reglas y leyes que permiten reducir expresiones lógicas y optimizar el hardware.

Las operaciones principales son el complemento (NOT), la suma booleana (OR) y el producto (AND). También se utiliza para representar decisiones lógicas en programación y sistemas digitales. Gracias a sus principios, se puede mejorar la eficiencia del hardware y reducir costos en su implementación.

🧠 ¿Cómo se relacionan? El álgebra de Boole se usa para diseñar y analizar circuitos lógicos. Cada operación booleana se puede representar con una puerta lógica, y combinando varias puertas se pueden construir circuitos complejos como sumadores, comparadores, memorias, etc.

Funciones y expresiones booleanas

Una variable booleana es aquella que solo puede tomar dos valores: 0 (falso) o 1 (verdadero). El conjunto B = {0, 1} representa estos valores. Cuando usamos varias de estas variables (por ejemplo, x₁, x₂, ..., xₙ), podemos formar lo que se llama una función booleana de grado n, que toma combinaciones de valores 0 y 1 como entrada y da como resultado 0 o 1.

Estas funciones se pueden representar mediante expresiones booleanas, que se construyen usando las variables y operaciones básicas como:

  • AND o conjunción(*) : producto lógico
  • OR o disyunción(+): suma lógica
  • NOT o negación (¬ o complemento): negación lógica
Por ejemplo, si E₁ y E₂ son expresiones booleanas, entonces (E₁ * E₂), (E₁ + E₂) y ¬E₁ también lo son.

Cada expresión representa una función. Para saber el valor de esa función, se reemplazan las variables con 0 o 1 y se realizan las operaciones. Dos funciones booleanas se consideran equivalentes si dan el mismo resultado para todas las combinaciones posibles de entrada.

Teoremas Booleanos

Regla del cero y la unidad

Toda operación simple que involucre un elemento con las variables binarias, queda definida:

  • 0 + A = A
  • 1 + A = 1
  • 0 * A = 0
  • 1 * A = A

    • Complementación

    Toda operación entre una variable y su complemento queda definida como:

  • A + A'= 1
  • A * A' = 0

    • Involución o doble negación

    Toda doble negación sera considerada como la variable natural.

  • (A')'= A

    • Absorción

  • A + A * B = A
  • A * ( A + B ) = A
  • A * ( A' + B ) = A * B
  • A'( A + B ) = A' * B
  • ( A + B ) * ( A + B' ) = A
  • A + A * B = A
  • A + A' * B = A + B
  • A' + A * B = A' + B
  • A * B + A * B' = A

    • Reducción

  • A + A' * B = A + B

    • De Morgan

  • (A * B)' = A' + B'
  • (A + B)' = A' * B'
  • A + B = (A' + B')'
  • A * B = (A' * B')'

    • Leyes del Álgebra Booleana

    • Identidad: A + 0 = A, A * 1 = A
    • Nulo: A + 1 = 1, A * 0 = 0
    • Complemento: A + A' = 1, A * A' = 0
    • Idempotente: A + A = A, A * A = A
    • Conmutativa: A + B = B + A, A * B = B * A
    • Asociativa: A + (B + C) = (A + B) + C
    • Distributiva: A * (B + C) = A * B + A * C

    Simplificación de expresiones booleanas

    Para reducir el total de términos de una expresión booleana existen técnicas como los mapas de Karnaugh o el método de Quine-McCluskey pero en programación generalmente es suficiente con las leyes del álgebra de Boole. Teniendo en cuenta que la condición lógica AND es el producto booleano, OR es la suma y NOT el complemento (que se puede representar con los símbolos * , + o ¬)

    • EJEMPLOS DE SIMPLIFICACIONES DE EXPRESIONES BOOLEANAS

    Ejemplo 1

    F = B + BB’

    Paso 1: Observamos que en los dos términos tienen la variable B en común, podemos aplicar la factorización.

    B + BB’ = B * (1 + B')

    Paso 2: Simplificamos lo que está dentro del paréntesis (1 + B'), quedando:

    B * (1 + B') = B * 1

    Paso 3: Aplicamos la Ley de Identidad:

    B * 1 = B

    Resultado final: F = B

    Ejemplo 2

    F(A,B) = A * B + A * B'

    Paso 1: Observa que ambos términos tienen la variable A en común, entonces podemos aplicar factorización.

    A * B + A * B'

    Paso 2: Factorizamos A fuera de la expresión:

    A * B + A * B' = A * (B + B')

    Paso 3: Aplicamos la Ley del Complemento B + B' = 1:

    A * (B + B') = A * 1

    Paso 5: Aplicamos la Ley de Identidad:

    A * 1 = A

    Resultado final: F = A

    Ejemplo 3

    F = A + AB + C

    Paso 1: Observamos que en los primeros dos términos tienen la variable A en común, podemos aplicar la factorización.

    A + AB + C = A *(1 + B) + C

    Paso 2: Simplificamos lo que está dentro del paréntesis (1 + B), quedando:

    A * (1 + B) + C = A * 1 + C

    Paso 3: Aplicamos la Ley de Identidad: A * 1 = A, simplificamos:

    A * 1 + C = A + C

    Resultado final: F = A + C

    Ejemplo 4

    F =(A + B) (A + C)

    Paso 1: Aplicamos la distributiva (expansión de productos).

    (A + B) (A + C) = A * A + A * C + B * A + B * C

    Paso 2: Simplificamos los productos A * A = A:

    A * A + A * C + B * A + B * C = A + AC + BA + BC

    Paso 3: Observamos que en los primeros tres términos tienen la variable A en común, podemos aplicar la factorización.

    A + AC + BA + BC = A(1 + C + B) + BC

    Paso 4: Simplificamos lo que está dentro del paréntesis (1 + C + B), quedando:

    A(1 + C + B) + BC = A * 1 + BC

    Paso 4: Aplicamos la Ley de Identidad: A * 1 = A, simplificamos:

    A * 1 + BC = A + BC

    Resultado final: F = A + BC

    Ejemplo 5

    F = xy[(x′z′) + 1] * (y' + x′) + (x + y)* (x′y)'

    Paso 1: Simplificamos lo que está dentro del corchete [(x′z′) + 1] ya que sabemos que en el algebra de boole cualquier cosa + 1 nos da como resultado 1:

    xy [(x′z') + 1] * (y' + x') + (x + y)*( x′y)'= xy (1) * (y'+ x′) + (x + y)* (x′y)'

    Paso 2:Aplicamos la Ley de Identidad: xz * 1 = xz :

    xy(1) * (y'+ x′)+(x + y)* (x′y)' = xy * (y'+ x′) + (x + y)* (x′y)'

    Paso 3:En los dos primeros términos, aplicamos la distributiva (expansión de productos):

    xy(y' + x') + (x + y)*(x′y)' = xyy' + xyx' + (x + y)*(x′y)'

    Paso 4:Simplificamos los productos xyy' y xyx' usando el teorema de complementación y*y'= 0 y x*x'= 0:

    xyy' + xyx' + (x + y)*(x′y)' = 0 + 0 + (x + y)*(x′y)' = (x + y) * (x'y)'

    Paso 5: Resolvemos el segundo término del lado derecho. Aplicamos el Teorema de De Morgan (x'y)' = x + y':

    (x + y) * (x'y)' = (x + y) * (x + y')

    Paso 6: En los dos términos, aplicamos la distributiva (expansión de productos):

    (x + y) * (x + y') = xx + xy' + yx + yy'

    Paso 7: Simplificamos los productos xx y yy' usando el teorema de complementación x*x= x y y'*y= 0:

    xx + xy' + yx + yy' = x + xy' + yx + 0 = x + xy' + yx

    Paso 8: Observamos que en todos los términos tienen la variable x en común, podemos aplicar la factorización.

    x + xy' + yx = x(1 + y' + y)

    Paso 9: Dentro del paréntesis aplicamos la Ley del Complemento y + y' = 1:

    x( 1 + y' + y) = x(1 + 1)

    Paso 10:y luego simplificamos dentro del paréntesis 1 + 1 = 1:

    x (1 + 1) = x (1)

    Paso 11: Aplicamos la Ley de Identidad: x * 1 = x, simplificamos:

    x(1) = x

    Resultado final: F = X

    Ejemplos de Demostrar la equivalencia

    Ejemplo 1

    A + AB + CD = AC

    Paso 1: Usamos la ley de absorción en los primeros dos términos A + AB= A

    A + AB + CD = AC
    A + CD = AC

    Resultado final: Demostramos que la equivalencia no es igual A + CD ≠ AC

    Ejemplo 2

    (x + z')' + yz * w' = x + yz

    Paso 1: Resolvemos el primer término. Aplicamos el Teorema de De Morgan (x + z')' = x' * z :

    (x + z')' + yz * w' = x + yz
    x'z + yz * w' = x + yz

    Paso 2: En los dos términos del lado derecho, aplicamos la distributiva (expansión de productos):

    x'z+ yz * w' = x + yz
    x'z + yzw'= x + yz

    Paso 3: Observamos que en todos los términos tienen la variable z en común, podemos aplicar la factorización.

    x'z + yzw' = x + yz
    z(x' + yw') = x + yz

    Resultado final: Demostramos que la equivalencia no es igual z(x' + yw') ≠ x + yz

    Ejemplo 3

    (AB)' + A = 1

    Paso 1: Resolvemos los términos del lado izquierdo. Aplicamos el Teorema de De Morgan (AB)' = A' + B':

    (AB)' + A = 1
    A' + B' + A = 1

    Paso 2: Aplicamos la Ley del Complemento A' + A = 1:

    A' + A + B' = 1
    1 + B = 1

    Paso 3: Simplificamos:

    1 + B = 1
    1 = 1

    Resultado final: Demostramos que la equivalencia es igual 1 = 1

    Compuertas Lógicas

    El álgebra booleana se utiliza para modelar los circuitos electrónicos. Un dispositivo electrónico está constituido por un número de circuitos. Cada circuito puede diseñarse aplicando las reglas del álgebra de Boole. Los elementos básicos de los circuitos se denominan compuertas. Cada tipo de compuerta representa una operación booleana

    Compuertas básicas

    • AND: Salida 1 si todas las entradas son 1. F = A * B
    • OR: Salida 1 si al menos una entrada es 1. F = A + B
    • NOT: Invierte la entrada. F = A'
      •

    Ejemplo de circuitos

    F= AB' + A'C' + B

    Circuitos Combinatorios

    Los circuitos combinatorios son sistemas lógicos donde la salida depende únicamente de las entradas actuales, sin usar memoria ni estados previos. Se construyen usando compuertas lógicas como AND, OR y NOT. Estos circuitos se utilizan para realizar operaciones básicas como sumas, comparaciones, decodificadores y más. La función que realizan puede expresarse mediante una expresión booleana.

    • Sumador: S = A XOR B, C = A * B
    • Codificador: convierte múltiples entradas en una combinación binaria.
    • Decodificador: convierte combinaciones binarias en múltiples salidas.
    • Multiplexor: selecciona una de varias entradas para enviar a la salida.
